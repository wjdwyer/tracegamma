# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good faith, keep criticism technical, and
accept that being shown wrong is the ordinary cost of doing careful work.

Report unacceptable behaviour to the maintainer at the address in
`DESCRIPTION` / `pyproject.toml`. Reports will be handled confidentially.
