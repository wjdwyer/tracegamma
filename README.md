# tracegamma

The **trace-gamma** distribution: a three-cumulant calibrated reference for
quadratic-form tests, with Welch's F and Pearson's chi-square as special cases.
Python and R implementations of one object, checked against each other.

| | Python | R |
|---|---|---|
| source | [`python/`](python/) | [`r/tracegamma/`](r/tracegamma/) |
| install | `pip install tracegamma` | `install.packages("tracegamma")` |
| docs | docstrings + doctests | `man/*.Rd` |
| tests | 99, pytest | testthat + parity fixture |

A test statistic that is a quadratic form `Q = a' M a` in a near-normal vector
has an exact null law — a generalized chi-square — with no closed form. The
trace-gamma is the closed-form shifted, scaled chi-square matched to its first
three cumulants, which are *exact traces* of one matrix product. Welch's F is
the two-cumulant member and Pearson's chi-square the equal-eigenvalue member,
so the family **contains** the classical references rather than competing
with them.

```python
from tracegamma import TraceGamma, imhof_ppf
tg = TraceGamma.from_eigs([4.0, 2.0, 1.0, 1.0])
tg.cutoff(0.05)        # 21.249374  -- the closed form
imhof_ppf(0.95, lam)   # 20.919385  -- the exact law, for comparison
```

```r
library(tracegamma)
tg <- trace_gamma(lam = c(4, 2, 1, 1))
tg_cutoff(tg, 0.05)    # 21.249374
imhof_ppf(0.95, c(4, 2, 1, 1))
```

## Cross-language parity

`parity.json` holds reference values generated by the Python package — 8
spectra x 9 quantiles plus parameters, branch, closed forms, cumulants,
cutoffs, both defects, standardized cumulants and the exact survival at each
cutoff. It ships in both packages, and the R test suite checks the R port
against it, so the two implementations cannot drift apart silently.

## Two things worth knowing

**The two-cumulant (Welch) branch is requested, not discovered.** No spectrum
of positive eigenvalues reaches the skewness floor in practice; you reach that
branch by supplying `k3 = 0`, which is how the paper states the special case.
A negative `k3` is discarded with a warning. Inspect `branch` to see which fit
you have.

**The exact-inversion method matters for small spectra.** The single adaptive
quadrature used in the original research code is accurate for ten or more
eigenvalues and unusable below three — worst relative error about 0.69 at one
eigenvalue, measured against the exact chi-square oracle. The default `panel`
method stays below 5e-9 throughout. Both ship; `method="quad"` reproduces the
published numbers exactly. See `python/src/tracegamma/exact.py`.
